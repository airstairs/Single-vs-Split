Viewport Meta Tag

Essential for Android web views and mobile browsers to prevent desktop scaling behavior.

<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">

Mobile CSS Best Practices

Optimize touch target sizes (minimum 48px by 48px) and eliminate annoying tap highlights.

/* Eliminate blue tap highlight box on Android */
* {
    -webkit-tap-highlight-color: transparent;
}

/* Ensure buttons are thumb-friendly */
button, .touch-target {
    min-height: 48px;
    min-width: 48px;
}
